# Superstore Sales Dashboard

## Описание проекта

Power BI-проект по анализу продаж, прибыли, клиентов и региональной эффективности на основе данных Superstore.

## Инструменты

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Основные задачи

- Анализ общей выручки и прибыли
- Расчет Profit Ratio
- Анализ продаж по регионам и штатам
- Анализ продаж по сегментам и категориям
- Анализ клиентов и заказов
- Анализ скидок и их влияния на прибыль
- Анализ динамики продаж по месяцам
- Определение наиболее прибыльных и убыточных товаров
- Создание интерактивных фильтров и визуализаций

## Основные KPI

- Total Sales
- Total Profit
- Profit Ratio
- Profit per Order
- Sales per Customer
- Average Discount
- Total Quantity

## Визуализации

- Продажи и прибыль по категориям
- Динамика продаж по месяцам
- Анализ по регионам и штатам
- Продажи по клиентам
- Анализ влияния скидки на прибыль
- Таблица продаж и прибыли по продуктам

## Результат

Дашборд позволяет комплексно анализировать продажи и прибыль, сравнивать регионы, категории и клиентов, а также выявлять факторы, влияющие на финансовый результат.
